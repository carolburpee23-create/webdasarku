🔗 Professional API Access

Structured Task
curl -X POST http://localhost:3000/automation/run \
-H "Authorization: Bearer default_secret_key" \
-H "Content-Type: application/json" \
-d '{
  "action": "visit",
  "url": "http://example.com",
  "steps": ["screenshot"]
}'
Natural Language Command
curl -X POST http://localhost:3000/automation/command \
-H "Authorization: Bearer default_secret_key" \
-H "Content-Type: application/json" \
-d '{
  "command": "buka google.com dan screenshot"
}'
